The native `lattice` CLI is a deterministic operator interface for workspaces,
Studio, providers, tools, capabilities, MCP, and integrations.

```sh
lattice provider list
lattice tool search "execute luau"
lattice tool inspect <tool-ref>
lattice mcp status
```

The command reference is generated from the structured CLI metadata and is
available under [Reference → CLI](../reference/generated/cli/).
